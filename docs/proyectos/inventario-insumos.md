# Control de inventario de insumos

<span class="chip">Excel</span> <span class="chip">Google Sheets</span>

## Contexto

La operación diaria dependía de tener los materiales disponibles a tiempo.

## Qué hice

- Llevé el registro metódico de los insumos.
- Hice el seguimiento del stock y el control de entradas y salidas.
- Garanticé la disponibilidad oportuna de materiales.

## Resultado

Mejor seguimiento del stock y disponibilidad de materiales para la operación diaria.
