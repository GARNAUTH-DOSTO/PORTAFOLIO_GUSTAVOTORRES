# Formulario digital de registro

<span class="chip">Google Forms</span> <span class="chip">Google Sheets</span>

## Contexto

La información operacional se registraba a mano, lo que generaba errores en los datos.

## Qué hice

- Diseñé y administré formularios digitales para la captura de información operacional.
- Validé los campos para mantener datos consistentes.
- Estructuré las respuestas en una hoja de cálculo para su consulta y reportes.

## Resultado

Reducción de errores manuales en el registro de datos.
